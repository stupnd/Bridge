Only need to do this if you added new libraries

1. Run the following (on your computer, make sure you're focused on the venv):

pip freeze > requirements.txt

2. Run the following (again, on your computer, in the right directory):

pip download --platform manylinux2014_aarch64 --platform manylinux_2_17_aarch64 --platform manylinux_2_28_aarch64 --platform manylinux_2_31_aarch64 --python-version 313 --implementation cp --abi cp313 --only-binary=:all: -r requirements.txt -d wheels/

3. Upload /wheels/ alongside your other files to PISHARE

4. Run (on the Raspberry Pi):

sudo python3 -m venv /opt/payload-venv
sudo /opt/payload-venv/bin/pip install --no-index --find-links=/opt/payload/wheels -r /opt/payload/requirements.txt
