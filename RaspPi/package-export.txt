Only need to do this if you added new libraries

1. Run the following (on your computer, make sure you're focused on the venv):

pip freeze > requirements.txt

1.5 Remove bleak and any 'win' dependencies from requirements.txt

2. Run the following (again, on your computer, in the right directory):

pip download --platform manylinux2014_aarch64 --platform manylinux_2_17_aarch64 --platform manylinux_2_28_aarch64 --platform manylinux_2_31_aarch64 --python-version 312 --implementation cp --abi cp312 --only-binary=:all: -r requirements.txt -d wheels/

# Download bleak on its own (no dependencies)

pip download --platform manylinux2014_aarch64 --platform manylinux_2_17_aarch64 --platform manylinux_2_28_aarch64 --platform manylinux_2_31_aarch64 --python-version 312 --implementation cp --abi cp312 --only-binary=:all: --no-deps bleak==3.0.2 -d wheels/

# Download a bleak dependency (dbus-fast)

pip download --platform manylinux2014_aarch64 --platform manylinux_2_17_aarch64 --platform manylinux_2_28_aarch64 --platform manylinux_2_31_aarch64 --python-version 312 --implementation cp --abi cp312 --only-binary=:all: dbus-fast>=1.83.0 -d wheels/

3. Upload /wheels/ alongside your other files to PISHARE

4. Run (on the Raspberry Pi):

sudo python3 -m venv /opt/payload-venv
sudo /opt/payload-venv/bin/pip install --no-index --find-links=/opt/payload/wheels -r /opt/payload/requirements.txt
